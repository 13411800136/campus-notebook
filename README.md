# 活动小本本

把校园活动录进网页，用**日历**和**列表**两种方式查看，一眼看出哪天有事、哪些还没做完；纯前端、免注册、**双击 `index.html` 就能用**。

## 项目用途

社团和学院的活动通知散在好几个微信群、QQ 群、班委转发和公众号推文里，当时看到了想着「回头再看」，事后再找就找不回来；还经常漏看截止日期，错过报名。

这个网页让你把活动名称、日期、类别和备注录进去，以后不用翻聊天记录——左边日历看哪天有事，右边列表按类别和状态筛，点日历某一天右边就只看那天。

## 主要功能

- **记一条活动**：名称（必填）、日期（必填，默认今天）、**时间（选填：只填开始，或填「14:00–16:00」这样的时间段；不填就是全天）**、类别（可自己增删）、备注（选填，**可以整段粘贴群消息原文**）
- **待办 / 历史两个标签**：待办只留还没做完、日期在今天及以后的；已完成、已过期、已删除都收进「历史」。**删掉的活动进「已删除」组，能恢复，也能彻底删除**
- **会聊天的 AI**：表单上方是个对话框。**打一句话**（「周三下午三点职业规划讲座」）、**拖进群消息 / 文档 / 截图**、**粘贴**、或点「＋」选文件 → 它会**接着上文回你**：能追问、能改主意（「不是周三，是周四」）、能问「我今天有什么」，也能纯闲聊。聊到某条活动说清楚了，它会给出一张写了名称 / 日期 / 时间 / 类别的结果卡，你点「**填入表单**」它才填，点「**存一条**」才真的存。**支持 `.txt` / `.md` / `.csv` / `.docx` / `.pdf` 和图片**（`.docx` 在本地解压读正文，不装任何东西；图片要靠支持看图的 AI）
- **可选 AI 接入**：在「AI 识别设置」里填自己的 API Key，对话框就真的会聊天了——**会记住前面聊过的内容**，也看得见你的待办（只发名称/日期/时间/类别，**备注不发**），所以问「这周还有什么」答得上来。Key 只存在本机浏览器里；没填、断网或调用失败都会**自动退回离线规则识别**，并在对话里写明原因，不填也完全能用
- **日历视图**：左边一个月历。有活动的日子挂圆点（数字 = **还没做完的条数**），那天全做完了就显示绿勾；可翻月，有「今天」按钮
- **可拖拽布局**：左右栏之间的分隔条能拖着调宽度；拖着的时候日历栏会**稍慢半拍地追手**，分隔条中间的水珠被拉长、松手弹回去（流体质感）；日历拉宽到格子够大时，**格子里直接列出当天的任务标题**（最多 3 条，多了显示「+N」）
- **日历和列表联动**：点日历某一天 → 右边列表立刻只看那天，上方出现「只看 X 月 X 日」标签（点 ✕ 取消）；录入表单的日期也跟着跳过去
- **今天 · 明天面板**：日历下方直接列出这两天还没做完的事，点一行跳到那天，点状态按钮就地打卡
- **到点提醒**：活动精确到几点几分；到点时页面顶部弹出醒目提醒条，浏览器允许的话还会发一条系统通知
- **活动状态**：点卡片上的状态按钮在「未开始 → 进行中 → 已完成」之间循环；做完的自动挪到「已完成」组，不再占「即将到来」的位置
- **按日期自动分组**：分「即将到来」（升序）、「已过期」（降序、变灰）、「已完成」（划线、变淡）；同一天里再按时间排
- **按类别筛选**：按钮可自己增删；右上角实时显示「当前 N 条」
- **改错不用重录**：点卡片上的「编辑」把内容填回表单改掉，就地更新，不会变成新增一条；表单里另有一个「清除名称和备注」按钮，想重打时不用逐个删
- **删除保护**：删除前弹确认框（写出活动名称）；确认后卡片会碎成几条往下掉，5 秒内可点「撤销」复原
- **输入校验与空状态**：名称或日期为空时红框提示且不写入；「一条都没有」「筛选无结果」「某天没有活动」各有对应提示，「筛选无结果」和「某天没有活动」还带一个「看全部」按钮
- **数据存在浏览器本地**（localStorage），关掉再打开还在

## 本地启动步骤（Windows 11）

1. 拿到代码：`git clone <仓库地址>`；没装 Git 就在仓库页面点绿色 `Code` → `Download ZIP` 解压
2. 打开项目文件夹
3. **双击 `index.html`**

预期结果：浏览器打开，左边是当月日历（今天那一格有底色标出），右边是「记一条活动」表单；第一次打开列表为空，显示「还没有任何活动」。

> 不需要装 Python / Node / 数据库，不需要联网，不需要命令行。
> ⚠️ `index.html` 必须和 `style.css`、`script.js` 待在同一个文件夹里，单独拖走会变成没样式的白板。

## 合成数据说明

- 仓库和演示中出现的所有示例活动**均为作者自编的合成数据**，不对应任何真实活动或真人
- 示例数据中**不含**真实姓名、手机号、学号、成绩；文中出现的「小林」是化名，非真人

## 已知问题 / 暂不支持

- **数据只存在本机浏览器**，换电脑、换浏览器、清缓存或用无痕模式打开都看不到之前的记录（无云同步）。想清空重来：F12 → Application → Local Storage → 删掉 `campus_events_v1`、`campus_deleted_v1`（已删除的历史）、`campus_tags_v1`（想要的类别会一起回到默认四类）→ 刷新
- **撤销条只留 5 秒**：过了 5 秒底部那条提示就消失，**但删掉的记录还在「历史 → 已删除」里，随时能恢复**；只有点了「彻底删除」才真的没了
- **不支持类别改名**：改名得删掉重建；删类别时，用它的活动会归到「未分类」，活动本身不会丢
- **至少要保留一个类别**，最多 8 个；「未分类」是系统保留的，不能手动添加
- **到点提醒只在页面开着时有效**：网页关掉就不会提醒（纯前端没有后台定时任务）
- **桌面通知可能拿不到授权**：浏览器的 `Notification` 接口要求安全上下文，用 `file://` 打开时部分浏览器会直接拒绝。这时只有页面内的提醒条，功能不受影响
- **规则识别只认固定写法**：`10月20日`、`14:00`、`下午3点`、`10/20` 这些能认；「下周三」「月底」这种相对说法认不出来，会留空让你自己填
- **AI 识别需要联网，而且不一定成功**：浏览器直接调第三方接口会被 **CORS** 限制，用 `file://` 打开时更容易被拦；被拦时会自动退回规则识别并在结果里写明原因
- **API Key 只存在本机浏览器**：不上传、不进仓库；换浏览器或清缓存就要重填。请不要把 Key 写进任何会被提交的文件
- **聊天必须有 Key**：本机没有能离线跑的大模型，所以没填 Key 时对话框只能认活动、不会聊天。想让它真的会聊，就在「AI 识别设置」里填一个
- **配了 AI 会把这些发出去**：你刚说的这句、前面最多 10 条对话、以及你的待办摘要（**只有名称 / 日期 / 时间 / 类别**）。**备注一个字都不发**——备注里常有群消息原文，没必要送出去。介意的话就别填 Key，纯离线用
- **它只记得这一会儿**：对话记录不存档，刷新就清空；它不会长期记住你说过的事
- **对话记录不保存**：对话框里的聊天只存在内存里，**刷新页面就清空**。识别出来的活动只有点了「填入表单」再「存一条」，才会真正存下来
- **一次最多认 4000 字**：贴太长会被挡下并提示。整本通知合集请只摘和活动有关的那几句
- **PDF 是「尽力而为」**：自己解析 PDF（不引任何库）。简单 PDF 能抠出文字；但中文 PDF 常用特殊字体，抠出来可能是乱码 —— 遇到乱码请复制文字，或截图后让 AI 看
- **老式 Office 格式读不了**：`.doc / .xls / .ppt` 是二进制老格式，本地解不开，请另存为 `.docx`
- **AI 的 `max_tokens` 不能省**：DeepSeek 的 `deepseek-flash` 是**推理模型**，会先花一部分额度在内部思考。程序里设了 `max_tokens: 4000`；删掉或调小的话，会出现「调用成功但正文为空」
- **图片识别需要支持看图的 AI 模型**：离线规则识别看不了图片；没配 AI 时会明确提示
- **桌面通知被拒绝后，浏览器不会再问第二次**：需要手动去「网站权限 → 通知」改成允许。在此之前，到点提醒仍然有**顶部提醒条**；页面切到后台时还有**标签页标题闪烁 + 一声提示音**（提示音可能被浏览器的自动播放策略拦掉），都不影响提醒条本身
- **删掉的活动会留在「历史」里**：想彻底清掉，在历史里点「彻底删除」，会二次确认
- **日历格子里的任务标题要拉宽才出现**：默认宽度下格子里只有数字和圆点，点某天在右边看详情；把分隔条往右拖到格子够宽（约 68px）才会显示标题，每格最多 3 条，多出来的显示「+N」。窄格子塞标题会全变成省略号，所以做了这个阈值
- 只保证手机宽度（375px）下上下堆叠不横向滚动，**没有做手机专用布局**

## 协同复盘（约 200 字）

这次全程用 Claude Code 配合。AI 帮我做了三件我自己做不了的事：写出代码骨架、把文档规范扒下来、生成四个方案互相评审。

但做决定的是我。我从四个方案里选了**功能最少**的那个，还砍掉了看起来最酷的「自动解析群消息日期」——因为评审发现它连自己举例的日期都算错了，对零基础是个工期黑洞。

检查上我没有只看页面好不好看。日期计算是我最不放心的地方，所以单独跑了跨月和跨年的测试，确认「还剩 N 天」是现算的、不是写死的。

最大的取舍是删除撤销：它最贵，一度想砍，最后还是做了——因为「不敢删」会让人不敢继续录。没做完的是数据不能跨设备，这条照实写进了上面的已知问题。

# 活动小本本

把校园活动录进网页，用**日历**和**列表**两种方式查看，一眼看出哪天有事、哪些还没做完；纯前端、免注册、**双击 `index.html` 就能用**。

## 这是什么

社团和学院的活动通知散在好几个微信群、QQ 群、班委转发和公众号里，当时想着「回头再看」，事后再找就找不回来；还经常漏看截止日期。

这个网页就是为这件事做的：**手动记一条**，或者**把群消息丢给 AI 让它代记**；左边日历看哪天有事，右边列表按类别和状态筛，点日历某一天右边就只看那天；到点弹窗提醒，记录能导出备份。

适合**要管的事不多、但时间点分散**的同学——不想为几件事装一个 App、注册一个账号，打开就能用。

## 主要功能

### 记下来

- **手动录一条**：名称（必填）、日期（必填，默认今天）、时间（选填，可只填开始，或填 `14:00–16:00` 时间段；都不填就是全天）、类别（可自己增删）、备注（可整段粘贴群消息原文，最多 500 字）、**提醒方式**（到点 / 提前 10·30·60 分钟 / 提前 1 天 / 不提醒）
- **对话代记**：表单上方是对话框。打一句话、拖进群消息/文档/截图、粘贴或选文件，它把活动**逐条**写进来
  - 一次能说好几件事（「周三讲座、周五辩论赛、下周一交材料」→ 一次 3 条，气泡里逐条列出，可整批撤销）
  - 支持 `.txt / .md / .csv / .docx / .pdf` 和图片（`.docx`、`.pdf` 在本地解析，不装任何东西；图片需要支持看图的模型）
  - **要不要人工确认由你定**：「直接记进列表（AI 自己决定）」或「先让我确认」——后者会先挂在气泡上，逐条点「记下」、一次「全部同意（N 条）」、或「都不要」
  - **它还能替你动手**：「把标枪那几条标完成」「删掉预约体测」「把辩论赛改到周五」——按编号找到对应活动执行，**删除永远要你先点**，每行都能单独撤销
  - 每次回复下面有一行折叠的**「思考」**，写清它为什么动这几条

### 找得到

- **日历**：圆点 = 还没做完的条数，全做完打绿勾，**过期没做完是琥珀色**；点某天 → 右边只看那天
- **搜索**：名称、备注、类别都能搜；日期也认——`10-25`、`10月25`、`2026/10/25` 都能命中；多个词是「都要有」；Esc 或 ✕ 清空
- **筛选与分组**：类别按钮叠加筛选，右上角显示「当前 N 条」；列表分「即将到来 / 已过期 / 已完成」，同一天再按时间排
- **撞车提示**：同一天时间段重叠的两条未完成活动，卡片上标「撞车」，悬停看跟哪条撞了

### 看得清

- **三种状态三色**：已完成 = 苔绿底 + 划线；已过期未完成 = 赭石底（待办页顶部还有「有 N 条已过期 → 去历史处理」入口）；已删除 = 灰色
- **今天 · 明天面板**：日历下方列出这两天还没做完的事，点一行跳过去，点状态按钮就地打卡
- **状态循环**：未开始 → 进行中 → 已完成，做完的自动进「已完成」组

### 不漏掉

- 每条可设提前提醒；时间一到**弹出大弹窗**（活动名 + 日期时间），三个按钮：**知道了 / 5 分钟后再提醒 / 标记完成**；多条同时到点会排队依次弹
- 同时还有顶部提醒条、标签页标题闪烁、一声轻提示音；授权后额外发系统通知
- 提醒条按真实剩余时间说话（「20 分钟后 15:00 · 职业规划讲座」）

> **系统通知需要 https 或 localhost**：双击 `index.html`（`file://`）时，Edge / Chrome 会直接拒绝通知权限、连授权框都不弹，按钮会写「桌面提醒需用 localhost 打开」。想要系统通知就**双击 `启动本地服务（双击我）.bat`**，浏览器会打开 `http://localhost:8899/`，再点「开启桌面提醒」；部署到 GitHub Pages 也一样。弹窗、提醒条、标题闪烁、提示音在 `file://` 下照常工作。

### 用得久

- **编辑就地更新**，不会变成新增一条；连点两次「存一条」只算一次
- **重复保护**：已有名称/日期/时间都一样的，表单下方会写明，并给「仍然要存 / 算了」
- **删除保护**：先弹确认框（写出名称），删掉的进「已删除」，5 秒内可撤销，之后也能在历史里恢复或彻底删除
- **输入校验**：名称为空、日期为空、日期超出 2000–2100 年、结束时间早于开始时间，都会红框并写明原因

### 备份与统计

- **导出**：一键下载 JSON（活动 + 已删除 + 类别）
- **导入**：本应用导出的 JSON，支持**合并**（按 id + 标题/日期/时间 去重，只加缺的）与**覆盖**；缺名称或日期的条目直接丢弃
- **简报**：生成本机文字版「今天 / 已过期 / 未来 7 天 / 总完成率」，可复制；配了 AI 还能润色成一段话直接发群
- **统计**：本月活动数、本月完成数、完成率、过期未完成数 + 按类别的条形图（canvas 手绘，不引库）
- **深浅色**：顶栏 🌙 / ☀️ 切换，默认跟随系统，选择会记住

## 快速开始（Windows 11）

| 想怎么用 | 怎么做 | 得到什么 |
|---|---|---|
| **最简单** | 双击 `index.html` | 完整功能；无系统通知；3D 背景退成纯色 |
| **要系统通知** | 双击 `启动本地服务（双击我）.bat` → 浏览器打开 `http://localhost:8899/` | 同上 + 可授权系统通知 |

打开后：左边是当月日历（今天有底色），右边是「记一条活动」表单；第一次打开列表为空，显示「还没有任何活动」。

> 不需要装 Python / Node / 数据库；`python -m http.server` 只有想开系统通知时才需要，双击那个 bat 就行，不用自己敲命令。

## 数据与隐私

- 数据只存在**你自己浏览器的 localStorage**：活动 `campus_events_v1`、已删除 `campus_deleted_v1`、类别 `campus_tags_v1`、左右栏宽度、深浅色、AI 的地址/模型/Key
- **核心功能全部离线**；只有可选的 AI 需要联网，Key 由你自己填、只存本机，不上传、不进仓库
- 配了 AI 时发出去的只有：你这一句 + 前 10 条对话 + 待办摘要（**只有名称 / 日期 / 时间 / 类别**），**备注一个字都不发**
- 示例数据全部是自编的合成数据，不含真实姓名、手机号、学号、成绩；文中「小林」是化名

## 已知问题 / 暂不支持

- **数据只在本机浏览器**，换电脑、换浏览器、清缓存、无痕模式都看不到之前的记录（无云同步）。想清空重来：F12 → Application → Local Storage → 删掉 `campus_events_v1` / `campus_deleted_v1` / `campus_tags_v1` → 刷新
- **撤销条只留 5 秒**：过了 5 秒底部提示消失，**但记录还在「历史 → 已删除」里**；只有点「彻底删除」才真的没了
- **不支持类别改名**：改名要删掉重建；删类别时，用它的活动归到「未分类」，活动本身不丢
- **至少要保留一个类别**，最多 8 个；「未分类」是系统保留的
- **提醒只在页面开着时有效**：网页关掉就不提醒（纯前端没有后台定时任务）
- **桌面通知要 https 或 localhost**：`file://` 下浏览器直接拒绝，详见上面的「不漏掉」一节
- **规则识别只认固定写法**：`10月20日`、`10/20`、`14:00`、`下午3点`、`周三`、`本周三`、`下周一` 能认；「月底」这类还是留空让你自己填
- **AI 识别需要联网，而且不一定成功**：浏览器直接调第三方接口会被 CORS 限制，`file://` 下更容易被拦；被拦时自动退回规则识别并写明原因
- **API Key 只存在本机浏览器**：不上传、不进仓库；换浏览器或清缓存要重填
- **聊天必须有 Key**：本机没有能离线跑的大模型，没填 Key 时只能认活动、不会聊天
- **它只记得这一会儿**：对话记录不存档，刷新就清空；但**它自动记下的活动是真的存了**
- **一次最多读 4000 字**：贴太长会被挡下，请只摘和活动有关的那几句
- **PDF 是「尽力而为」**：自己解析、不引库；简单 PDF 能抠出文字，中文 PDF 可能乱码——遇到乱码请复制文字或截图给 AI
- **老式 Office 格式读不了**：`.doc / .xls / .ppt` 请另存为 `.docx`
- **AI 的 `max_tokens` 不能省**：`deepseek-flash` 是推理模型，先花额度在内部思考；程序里设了 4000，调小会出现「调用成功但正文为空」
- **图片识别需要支持看图的模型**：离线规则看不了图片
- **删掉的活动留在「历史」里**：想彻底清掉，在历史里点「彻底删除」（会二次确认）
- **日历格子里的任务标题要拉宽才出现**：默认宽度只有数字和圆点，把分隔条拖到格子够宽（约 68px）才显示标题，每格最多 3 条
- **没做手机专用布局**：只保证窄屏（≤900px）上下堆叠、不横向滚动

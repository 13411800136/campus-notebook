当前：规则识别

填一个 API Key，上面这个框就变成真的能聊天的助手：可以追问，可以改主意（「不是周三，是周四」）， 也可以问它别的事。说到一条活动，它会自己记进列表，不用你点存——记错了点「撤销」就回来。 Key 只存在你这台电脑的浏览器里，不会上传到任何地方。 没填、断网、或接口调不通时，会自动退回本机规则识别——那只能认活动，聊不了天，其余功能不受影响。

选「先让我确认」时，识别出的活动会先挂在对话气泡上，点「记下」或「全部同意」才写进列表。让它改状态、改内容、删掉某条时也一样在气泡里点；删除永远要你确认，删掉的还在「已删除」里，能恢复。
